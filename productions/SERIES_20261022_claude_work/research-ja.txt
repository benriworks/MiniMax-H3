公式で確認したこと
1. Docs、Slides、DesignはFree／Pro／Max／Team／Enterpriseに提供される。Cloud code execution and file creationの有効化が前提。Enterpriseでは組織設定も関係する。表示・残り利用枠は手元で確認する。
2. Docsは会話から頼める。/docs又はOutput > Docs、Artifactsからの開始も案内される。目的・読者・載せる内容を指定し、最初の出力を見て修正する。
3. Slidesは会話中のメモ等を使う資料作成用のテンプレート。直接編集とPowerPoint/PDF出力が案内される。
4. Designは会話、コメント、直接編集で反復する。部分の見た目と全体構造で依頼方法を使い分ける。デザインシステムは既に設定されている前提の説明もあるため、未設定なのに自動で自社ブランドを継承すると断定しない。
5. 一般Artifactsガイドは文章選択後のEdit with Claudeを案内。Docsガイドにはコメントで@Claudeに依頼する方法もある。撮影時に見えている方を使い、存在しないボタンを模した画面は作らない。
6. DocsはWord、SlidesはPPTXに出力可能。ただし書き出しの操作だけで品質を保証せず、得たファイルを対応アプリで開いて確かめる。
7. 2026-10-08はDocs/Slides/Design正式提供の発表日。画面撮影日・提供確認日とは区別する。Motion/Dashboardsは今回の5本に含めない。

撮影に必要な画面と保存するもの
各回共通：個人アカウント情報を含む全画面の原本は非公開の証跡とし、公開用は撮影対象だけの画角にする。実在の仕事・受信箱・既存ファイルを使わず、新しい撮影用会話と架空資料を使う。
01 Docs：依頼直前／依頼送信／初回文書全体／追加修正依頼／修正箇所／数字と未定欄。初回の本文と修正後の本文を別保存。
02 Slides：依頼／5枚の一覧／表紙・内容・日程／文字量を直す依頼／修正前後。初回と修正後の各ページ画像又はファイルを保存。
03 Design：依頼／初回告知／部分指定／修正後告知。同じ倍率の前後比較を作る。拡大率の違いを文字改善に見せない。
04 部分修正：修正前本文／文の選択／編集依頼UI／修正後／変更外の主要数値。最終稿は実際に選択した文に合わせる。
05 書き出し：DocsのExport／取得docx／SlidesのExport／取得pptx／対応アプリで開いた全ページ／保存先。実際に使ったアプリ名とファイルハッシュを記録する。

公式引用の公開画角
公式画面は見出し・短いUI名を対象とし、根拠の短い引用カットとして使う。一般的な仕様の日本語解説は別レイヤーで表示。ページ全体や段落全文は証跡用途で保存しても公開動画へ入れない。
claude_docs：Create a doc / Edit directly / Export a doc 合計8語。
claude_artifacts：Slides / Edit and iterate / Edit with Claude / View and export 合計10語。
claude_design：Refine your design / Edit directly on the canvas 合計9語。
claude_oct8：October 8, 2026 / Docs, Slides, and Design 合計8語。
引用文字が増えるときは再集計する。出典表示は『引用：Anthropic公式ヘルプ』、ドメインsupport.claude.comを読みやすく添える。発表ページのみclaude.comとする。本文を塗り替えた公式風画像は作らない。

撮影ができない場合
ログインや機能表示の不足がある場合は撮影待ちとして報告する。自作のモックを実際のClaude出力に置き換えない。未収録の動画を実証済みとして完成扱いにしない。
