# v01の検証とレビュー境界

確認日：2026-11-02。

| 対象 | 検証結果 | 境界 |
| --- | --- | --- |
| 提供原本12、ZIP展開64 | 終了時に全容量とSHA-256一致 | 元コード実行・元blend読込はなし |
| ショート | 30.291667秒、727フレーム、1080×1920、24fps、全decode成功 | 人の全編試聴・採用は未完了 |
| フル | 149.5秒、3588フレーム、1920×1080、24fps、全decode成功 | 終了画面10秒を含む。YouTubeの実要素設定は別 |
| 最終AAC音量 | short -16.01 LUFS/-2.28 dBTP、full -16.02/-1.63 | 実AACのinput値。測定用loudnormの再変換output値ではない |
| 実フレーム | 3枚/ターンと終了画面、short16枚/full52枚を保存し接触シート確認 | 全フレームを人が見た検査ではない |
| 独立AI音声点検 | 台本を渡さず実MP4音声を点検、両方指摘なし。ドッツ/ブレンダー、フルのパイソンも認識 | 人の最終採用ではない。API再試行はしていない |
| 記事素材ZIP | 画像8点含む19項目。CRC/全member SHA-256、画像参照8件一致 | 元撮影・API応答・モデル・動画・音声は含めない |
| 共通台帳 | revision22、ready=true、blocker/warningなし | technical_verified=falseはサービスの固定欄。媒体QCとは区別 |
| Drive共有 | 2動画とZIPの名前・容量・親・所有者をreadback照合。PCで動画再生と進行を確認 | 同じ所有者アカウントでの確認。権限を広げず、スマホ実機未検証 |
| 記事表示 | オフラインのHTML参照検査成功 | local fileのブラウザ表示はURLポリシー拒否。迂回なし。媒体上のスマホ表示は未検証 |
| Python/共通部品 | ケース7本のcompile成功、共通Canvas既存3テスト成功 | Studio全体の新規機能やCIの確認とはしない |

最初のショートはone-pass音量が不足し、初回出力を `work/first-QC-short/` へ保持。2-pass正規化へ切り替えて映像と音声生成をやり直さず最終AACを実測した。字幕枠の高さ不足は本番出力前に枠を広げ、文字サイズを維持した。packageのサムネイル呼出名エラーはCanvas.textへ修正し、ZIP検証も再実行した。

再確認は `python productions/content-projects/CONTENT_20261102_dots_blender_wine/validate_delivery.py`。媒体・原本がignoredのため別cloneへコードだけを取得しても実行素材は付属しない。

レビューでは、注ぎ終わり比較で変更点が伝わるか、瓶の比率の説明が分かるか、掛け合いとBGMのテンポがよいかを確認する。変更は対象シーンを絞り次版へ保存。YouTube・ブログへの公開やmainマージは行っていない。
