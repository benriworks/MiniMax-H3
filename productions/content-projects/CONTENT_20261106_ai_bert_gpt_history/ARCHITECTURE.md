# 【AI】BERT・GPT誕生史の制作構成

更新：2026-11-06。本書は案件の素材・文書・将来の制作接続を記す。共通Studioの実装変更はない。別資料の[Mermaid図](ARCHITECTURE_DIAGRAM.md)と独立して維持する。

制作窓口はチャット。一次論文・公式発表の調査を、出典台帳・企画・会話・記事へ結ぶ。白衣版v02と構成v01を明示採用済み。初回short v03／full v02は技術確認後、ユーザーが編集品質を差し戻した。最新short v07／full v05は既存43台詞・声・一定BGMを維持し、別Rendererで主図・原図引用・具体例・人物画角を改訂した。ローカル人物素材は旧10＋胸上2を保持。両動画の全decode・字幕・音量・指定箇所の実フレームとDrive保存読戻しを確認した。記事v04・PDFv06も共有。人の最終試聴・完成品採用・公開は未完了。最新の数と状態は[再開記録](RESUME_AND_KNOWHOW_JA.md)を正とする。

軽量な正本は本案件フォルダー。生成静止画、論文PDF、引用派生、音声、動画、レビュー、共有受領は同じ案件IDのoutputs配下に保存する。キーや私的URLをtracked文書へ入れない。動画と記事は主張・原素材を共用し、縦・横・記事の派生と確認状態を分ける。

共通CLIの既存 `research / capture / proposal / feedback / asset / character / article` を用いて準備状況を保存する。人物承認・企画採用は実際の返答を確認して別操作で記録する。doctor成功を生成成功へ置き換えない。

## 初回候補から継承する実行処理

| 処理 | 役割と境界 |
| --- | --- |
| `start-local.ps1` | 専用8192番、分離したinput/output/user/database。起動前doctorと起動後のserving PID・出力先を照合。他アプリを停止しない |
| `generate_motion.py` | 既存のdurable H3 runnerの投入ID・原本・資源監視を再利用。現在はQ3 diffusion／Q2 text encoder／Turbo8-step。失敗2設定の保存先を残し、曖昧な投入を自動再送しない |
| `generate_voices.py` | 表示・読みを分けた台詞ごとに既存Geminiキャッシュを使用。拒否・不明な結果の自動再送なし。キーはユーザー環境変数から読み、値を保存しない |
| `frame_presenters.py` | 白背景の人物専用に頭部の尺度・位置を追跡し、原本と別の派生画像でカメラの寄りを補正。元動画・実演・比較対象は変えない |
| `produce.py` | PCM実尺から縦横それぞれを配置し、共通の字幕整形・Canvasを利用。人物原本を保持して必要な画角補正だけを編集へ適用。図は説明用と実測を区別 |
| `audio.py` | ローカル許諾音源をhash照合。声量調整と低めの一定BGM。発話ごとの減音／復帰・頭尾boostを今回使わず、共通既定は変えない。最終mixは二段階の音量測定で正規化 |
| `review_media.py` | 既存の有界なGemini検査transportを案件出力へ接続。実音声・実映像のAI補助で、人の試聴・媒体QC・採用とは別 |
| `prepare_article.py` | 8つの図を記事用に直接描画、原論文の題名3引用と共通草稿をHTML/ZIPへまとめ、全member SHAを検査。blogのMDX・公開処理ではない |
| `record_workspace.py` | 実際の生成物・記事図・実尺絵コンテを既存の共通台帳へ登録。既存の人物承認・構成採用は変更せず、媒体QC・採用・公開は個別に記録 |
| `package_pdf.py` | 同HTMLから日本語フォント入りのレビューPDFをオフライン生成。図の固定寸法と図・キャプションの次ページ送りを点検。PDFv04と原HTMLは別の派生 |

全コードはこの案件の制作処理。共通Studioへ未実装の機能を追加済みと説明しない。フル末尾は10秒の終了画面用余白を持ち、音声検査がこの無発話区間を指摘しても意図を照合する。

処理順は単体参照→ローカル試験→感情素材→実音声と図の配置→縦横それぞれの書き出し→字幕・全decode・音量・実AV→Driveレビュー。個別コマンドを助手が実行し、接続しただけで自動実行・公開されるシステムではない。記事HTMLのブラウザ確認ではfile経路を開けず、ローカルサーバー開始のコマンドも自動審査が拒否したため、迂回せずオフラインPDFを作成した。ブラウザ・スマホの確認済みとはしない。既存完成動画は変更せず、原本・改訂・hashを保持する。

## 指定された編集改訂の構成（short v07 / full v05）

初回候補はユーザーが編集品質を差し戻した。[改訂の対応表](EDITORIAL_REVISION_V04_JA.md)を正とし、旧版の技術確認を品質合格へ読み替えない。白衣v02・声・実音声の配置は保持し、旧Rendererを上書きせず、`produce_v04.py` に新しい構図と図解・原図の提示順を実装した。

- `fetch_official_v04.py`：公式記事HTMLの実リンクから原図を取得し、原本URL・hash・寸法を保存。ブラウザ撮影ではない。BERT原論文Fig.1は別の2260×675描画原本と座標・倍率・出典を保存する。
- `generate_closeups_v04.py` と `motion-prompts-v04-closeups.json`：同じ承認済み人物から作った胸上参照を専用v04出力・サービスへ投入。過去のdurable runnerとQ3/Q2 Turbo条件、資源監視は維持。2件の後、自己所有の空キュー・PIDを確認して停止。
- `produce_v04.py`：縦横の明示したショット割り、同じ図の段階更新、具体的な言葉と絵、公式原図の全体→モデル別の寄り、日本語の図外解説、顔アップ・胸上・対話・説明の脇の人物動画を配置。字幕と原図は別領域。原図の文字は描き直さない。生成文字のない上部領域と、用途別の切り出しを別派生で使用。
- 音声は `audio.py` の既存処理を呼び、元の43台詞と一定BGMを再利用。音声再生成はない。変更した動画の版だけ新しくmux・全decode・測定する。
- `review_editorial_v04.py`：ユーザーの5指摘を基準に実AVのAI補助を行い、指摘は原寸の実フレームで再確認。APIの合否を編集採用にしない。縮小原図の指摘を受けて原論文の高解像度描画と部品別表示へ修正した。
- `package_article_v04.py` と `package_pdf.py`：共通草稿v04、直接描画の図7枚と公式引用4枚、可搬HTML/ZIP、図入りPDFv06。正方形の補助写真はPDFで285ptに抑え、横長の図は読み取れる固定幅を保つ。
- `record_revised_v04.py`：新しい原図と人物素材、最新版の媒体・実尺ショット割り・記事を既存台帳へ保存。承認済みの顔・構成を承認し直したり、未確認の完成品を採用済みにしない。native人物の脇表示を、共通PIPの音声強度連動口パク済みとは記録しない。

共通Studioの機能追加や自動での編集品質採点を実装済みとするものではない。この案件で検査・制作した範囲と、共通規約への教訓の反映を分ける。YouTube・ブログ公開は別操作で未実施。
