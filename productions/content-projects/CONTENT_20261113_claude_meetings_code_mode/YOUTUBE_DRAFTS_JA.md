## フル

**【Claude】Google Meetの会議中に議事録・資料を作る｜Claude MeetingsとCode Mode**

ClaudeがGoogle Meetに参加し、議事録に加えて会議中に資料を作るClaude Meetings。公式画面で、参加者への追加からホワイトボード、会議後のアクション項目までをたどります。Code Modeは、ファイルを探す・読む・まとめる作業で説明します。
