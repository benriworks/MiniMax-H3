## 企画v01

仮題「日曜、海に行かない？」。父からの電話を後回しにしていた娘が、昔の海の写真を見つけ、自分から電話をかけ直す。舞台を雨の日の一室に絞り、手元、表情、電話越しの返事で気持ちの変化を見せる。

| 時間 | 画面と音 |
| --- | --- |
| 0〜3秒 | 「父」からの着信。主人公の指が止まり、着信を見送る。着信表示は編集で合成。 |
| 3〜8秒 | 封筒から桟橋の写真を取り出す。試験カットを候補にして、袖・机・窓の光を人物カットと合わせる。 |
| 8〜13秒 | 裏面に手書きの「また、二人で。」。紙の音を残し、文字は編集で合成。 |
| 13〜19秒 | 顔に寄り、迷いがほどける。主人公が父へかけ直す。 |
| 19〜30秒 | 「お父さん、日曜、海行かない？」に、父が「じゃあ、おにぎり作っとくか」。写真を握る手がゆるみ、主人公の小さな笑顔で終わる。 |

主人公は架空の成人。暗いニットの袖で試験映像とのつながりを持たせる。父は電話越しの声。顔立ち・衣装は採用済み。声は提案段階。BGMとセリフは別素材とし、雨音・紙の音・呼び出し音を場面の変化に使う。字幕と読み上げ原稿は分ける。

### 主人公と封筒の基準画

水野 真帆、32歳の架空の会社員。離れて暮らす父の連絡に「あとで」と返しがちだが、写真を手にして自分から次の約束をする。肩までの黒髪、暗いチャコールのニット。雨の窓と使い込んだ木の机を試験カットと合わせ、目線と手の力が変わる小さな演技を目指す。父は電話越しの声で登場する。

### セリフとBGM

セリフの文面、間、発話の画角を先に決め、本番の音声は映像の編集時に別トラックで重ねる。顔を寄りで見せる場面は、読む前と返答を聞いた直後の表情を使う。真帆の発話は肩越しから手元と写真を見せ、父の発話は電話越しの短い返答にする。口元を見せる演出へ変更する場合は、声を先に録ってから口の動きを合わせる。

| 時刻の目安 | 音と編集 |
| --- | --- |
| 0〜3秒 | 雨音に短い着信音。着信を見送る指の動きと合わせる。 |
| 3〜13秒 | 雨と紙の音。写真を裏返す音で切り替え、手書きの言葉を読める間を取る。 |
| 13〜19秒 | ピアノの単音を控えめに入れ、かけ直す動作へ。 |
| 19.4〜22.5秒 | 真帆のセリフ。表示原稿は「お父さん。日曜、海行かない？」。言い出す前にひと呼吸。 |
| 23.3〜26.4秒 | 父のセリフ。表示原稿は「じゃあ、おにぎり作っとくか。」。電話越しの音質に寄せる。 |
| 26.4〜30秒 | 写真を持つ手がゆるむ。声のない余韻を残し、雨とピアノを静かに終える。 |

上の時刻は絵コンテ上の仮配置。収録後は実尺を計り、台詞間の沈黙と字幕の開始・終了を調整する。GeminiのAoedeは真帆の声の候補として短く試聴し、父の声も別に確認する。BGM・セリフ・環境音を別ファイルで保持し、発話の合間で音量が大きく戻らないようにする。生成音は使える紙音等を選ぶ。曲の採用と収録はこれから。 [読み上げ原稿](dialogue-read-v01.txt) · [ナレーション別冊](../../../docs/video-production/NARRATION_HANDOFF_JA.md)
