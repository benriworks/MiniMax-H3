# 利用枠共通化ニュースのショート制作構成

`script-v01.json` に読み原稿、表示原稿、意味ごとの字幕、場面、公式根拠を保持する。`voices.py` は共通dialogue_narrationでAoede／Charonを8発話生成し、実PCMと証明を保存。不明・拒否応答を自動再送せず、検証済み素材をhash照合して再利用する。

`produce.py` は公式・設定画面の原本から私的情報を除いた短い公開派生を作り、既存承認済み人物素材を再利用する。共通 `tools/studio/explainer_canvas.py` は実際の文字の見える範囲で中央揃えを行い、はみ出しを検出し、改行時に英数字の製品名を分断しない。既存完成動画の文字処理は変更しない。

ChatGPTとCodexから一つの枠へ進む線、Instantの迂回、WorkからメインChatGPTへの移行、モデル・作業依存、現在のUsage入口、未記載条件を1080×1920・24fpsで描画する。池の水面と粒子には目盛りを付けず、量や消費比率を実測したグラフとしない。予定と実画面の役割を表示で分ける。

話者の口は実PCMの音量に応じた簡易開閉、聞き手は既存MiniMaxの反応動画。字幕は実音声の発話区間に合わせ、句内は文字数の推定配分。BGMはsunny_loopと既定explanation_v1、控えめな改善SEで別stemから合成する。

セリフ別MP4を連結し、H.264映像とAACステレオ48kHzの47秒に書き出す。凍結したv01の再開は原稿・素材・実媒体hashを照合し、変更は新しい版で行う。初回出力と字幕3カットの修正前はwork以下へ保持し、声の再生成はしない。

`verify.py` は最終MP4の25確認画像と、原稿を与えない独立AI音声点検を保存。全decode・実寸・実尺・frame数・音量の検査はproduceにも持つ。`package.py` は記事用のネイティブ1920×1080図3点、短い公開引用4点、草稿HTML・Markdown・字幕・出典・検証要約をZIPへまとめ、全member hashとCRCを照合する。

`register_workspace.py` は共通企画台帳にユーザー依頼の範囲、公式根拠、現在の設定の観察、公開素材、9場面と記事を保存する。設定の観察を架空素材の消費実験として登録せず、媒体のQCと準備判定・採用・公開も区別する。Driveを優先し、プレーヤー読み込み中の場合にS3を代替とする。署名URL・生応答・私的原本・動画・音声・ZIPはGitに入れず、軽量コードと文書のみ個人forkへ保存する。
