# フル動画v02：最後の10秒と終了画面の設定

本編の内容と36セリフを引き継ぎ、約6:53からの称賛を光の粒・帯・柔らかなにじみへ変更。7:14.333から7:24.333まで、発話のない終了画面を10秒追加した。BGMは連続し、最後1.2秒を穏やかにフェードする。

動画へ焼き込んだ背景は、**関連動画2枠とチャンネル登録1枠を置くための余白**。クリックできる動画・登録要素は、YouTube Studioで追加する。動画を作っただけで実際のリンクや登録機能が付いたとは扱わない。今回YouTubeの投稿や設定は行っていない。

## YouTube Studioで置くもの

1. 投稿する動画の「エディタ」→「終了画面」を開く。
2. 動画を2つ、チャンネル登録を1つ追加する。動画は特定の動画・最新アップロード・視聴者向けなどから選べる。
3. 3要素の開始を本編終了の **7:14付近**、終了を動画の終端 **7:24付近** に合わせる。設定できる時間精度に合わせ、会話には重ねない。
4. 配置ガイドに合わせて左右に動画、中央にチャンネル登録を置き、プレビューして保存する。

## 配置の目安（1920×1080）

| 要素 | 領域 |
| --- | --- |
| 左の動画 | x=148〜708、y=430〜745、560×315（16:9） |
| 右の動画 | x=1212〜1772、y=430〜745、560×315（16:9） |
| チャンネル登録 | 中心960,590、半径120の円を目安にする |

動画側では各領域を安定した背景にし、動く光が要素の背後へ入り込まないようにした。実際のYouTubeの枠サイズや配置はプレビューで調整する。文字の上へサムネイルを広げない。
