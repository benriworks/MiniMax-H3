## 音声と画像の来歴

Aoedeナレーションは全場面の原稿、発音辞書、WAVを再利用。新しいAPI送信は0回。準備時に前版とのナレーションWAVのバイト一致を検査する。声を変えず、既存の栞のMiniMax人物動画を冒頭と締めで全面使用する。

撮影原本はComputer Useが返したJPEG。Studioの検証契約に合わせ、デコード後の画素をPNGへ保存した文脈画像と、矩形切り出しを作る。原本のJPEGを別途保持し、拡大・文字の再描画・AI編集は行わない。PNG化によって元の情報が回復したとは扱わない。

## 再開と保存

`produce.py render`で既存の固定storyと音声を検証し、未完了の工程から再開する。撮影画像の取り込みはbuild初回だけ。storyと証拠ファイルは固定、進捗stateだけを更新する。共通Studio処理の変更はない。

ローカル確認入口：`outputs/content-projects/CONTENT_20261023_claude_docs_reuse/review/v03/index.html`。原稿・画像受け渡しは同案件の`blog-handoff/v03/`。動画は既存production ID配下の新しい時刻フォルダーへ保存し、前版を上書きしない。

Driveは版付きレビュー動画とPDFを保存する。名前・容量・親フォルダー・アクセス状態の再取得を確認する。モバイル実再生、最終試聴、ユーザー採用、公開は別の確認項目とする。GitHubには構成、手順、検査要約を残し、動画・音声・非公開原本・Drive URLは含めない。記事と公開用画像はブログのdraft PR #85へ保存する。
