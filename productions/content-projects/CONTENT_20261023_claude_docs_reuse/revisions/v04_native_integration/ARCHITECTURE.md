# 実画面差し替え処理の構成

既存Studioへ入力する案件固有のアダプター。アプリ共通処理に変更はない。

`produce.py`は撮影台帳からJPEG原本を照合し、PNG文脈画像と公開用の矩形切り出しを作る。撮影日時、元ファイルのhash、座標、架空素材と個人情報の確認、表示だけを行った範囲を証拠へ記録する。画像とstoryは固定して保存する。

前版のstoryを複製し、4場面を実画面へ置き換える。production IDは検証済みナレーションとの対応を維持し、storyの改訂パス、review_revision、出力時刻で今回の版を特定する。原稿・発音辞書・話数が変わった場合は再利用の照合を失敗させる。

既存Aoedeの音声証拠を検証してprepareへ渡し、前版と準備済みナレーションWAVのバイト一致を確認する。共通rendererが映像を生成し、finishが形式、音量、全デコードを検査する。AI画面確認とユーザーの最終試聴は別の状態で持つ。

記事では同じ撮影の公開用画像3枚をブログへコピーし、hashを照合する。MDXの説明と画像を更新し、7画像を含むHTML/PDFを版付きで保存する。GitHubへ渡すのは記事、公開画像、軽量な構成と検査記録。原撮影と署名URLはローカルに残す。
