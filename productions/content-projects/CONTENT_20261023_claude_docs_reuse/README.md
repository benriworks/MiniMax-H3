## 保存と検証

PCの案件台帳は同フォルダーの `content-project.json`、動画台本は `creator-story.json`。処理は `produce_pilot.py`。原本、派生画像、音声、動画、レビューは `outputs/content-projects/CONTENT_20261023_claude_docs_reuse/` と `outputs/productions/SHORT_20261023_claude_docs_blog/` から追う。

共通CLI：`python -m tools.studio.content_projects validate --project productions/content-projects/CONTENT_20261023_claude_docs_reuse/content-project.json`。受け渡しは同コマンドの `export-blog --revision vNN`。既存版は上書きしない。

動画の全デコード、尺、フレーム、音声形式、音量、AI補助の画面確認を実施。人による最終試聴・モバイル再生・公開承認は未実施。ブログでは内容・画像参照・型・Lint・既存テストを確認する。数値はローカル検証記録へ保存し、未実施の検証を合格と書かない。

DriveのレビューURLと個別ファイルIDを含む受領記録はローカルに残す。GitHubへはこの工程、課題、コード、公開可能な台帳・出典を残す。動画本体・音声・個人情報入り撮影原本はGitHubへ保管しない。
