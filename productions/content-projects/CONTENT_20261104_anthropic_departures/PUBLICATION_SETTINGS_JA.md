# 今回の投稿メモ：Content ID登録なし

2026-11-05。対象はanthropic-departures-short v02、BGMは甘茶の音楽工房「夕暮れのキャンパス」。ユーザーの「間違えて設定しないようにしたい」を反映した投稿手順で、アカウントの設定変更やロックを行った記録ではない。

| 項目 | 今回の扱い |
| --- | --- |
| 動画の投稿 | 通常のYouTube Studioからアップロードする |
| 動画のライセンス | 既定の「標準のYouTubeライセンス」を使う。Content IDの権利登録とは別 |
| Content IDへの権利登録 | この音源や完成動画を、独占的な権利を持つ参照素材として登録しない |
| 外部サービスの権利管理 | この作品をContent IDへ登録する配信・権利管理サービスは利用しない。サービスを使う場合は、その登録対象に含まれないか確認する |
| 投稿時の自動著作権チェック | 通常の照合。投稿者がContent IDへ権利登録したことを意味しない |
| 通常の広告収益化 | Content ID登録とは別。チャンネルの利用資格などに従って判断し、登録禁止だけを理由にオフへ変更しない |

[YouTube公式のライセンス説明](https://support.google.com/youtube/answer/2797468?hl=ja)は、標準ライセンスを通常のアップロードの既定としている。[Content IDの使用](https://support.google.com/youtube/answer/3244015?hl=ja)は、承認された権利者向けのコンテンツマネージャの手続きとして説明されている。[利用資格](https://support.google.com/youtube/answer/1311402?hl=ja)には、参照素材への独占的な権利が必要とある。

今回の音源の[配布規約](https://amachamusic.chagasi.com/terms.html)を2026-11-05にも確認。映像BGMとしての利用と、Content IDへの登録を区別する。クレジットは[TITLES_AND_PUBLICATION_V02_JA.md](TITLES_AND_PUBLICATION_V02_JA.md)から使う。動画と音声の作り直し、YouTubeへの投稿、アカウント・外部配信サービスの設定操作は行っていない。実際のアカウントの登録状況は未確認。
