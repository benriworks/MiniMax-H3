# 「灰の街」の制作アーキテクチャ

2026-11-15更新。映像の制作手順は [案件記録](RESUME_AND_KNOWHOW_JA.md) と [制作ノウハウ](../../../docs/video-production/H3_ACTION_DRAMA_KNOWHOW_JA.md) を入口にする。設計図は独立した [ARCHITECTURE_DIAGRAM.md](ARCHITECTURE_DIAGRAM.md)。

映像は設定画・絵コンテからH3の5秒カットを作り、`assemble_sequence.py` が保存済みカットを組み立てる。ニュース、受信画面、時間テロップは別の後処理で配置する。動画・音声・生成応答は主cloneの `outputs/` に置き、プロンプト・制作コード・記録はGitへ分ける。

通しBGMは生成と編集を分離する。新規Lyria原音のリクエスト・応答は媒体フォルダーへ保存し、`render_full_score.py` は `score_full_v01.json` と保存済み3原音だけを読む。原音hash・形式を確認し、短いクリップ波形の補間、低域調整、区間切り出し、音量曲線、クロスフェード、静的マスターゲインを適用する。無音区間とピークを検査し、180秒の単体WAVと原音・コードhashを含む台帳を出力する。

出力が存在すれば停止する。API再送、動画の上書き、配信・公開はこのレンダラーの責務に含まない。媒体ルートを引数で受け取り、別worktreeでも主clone側の原音を照合して使える。サンプル・音量検査とAI補助聴取は人の試聴・採用から分けて記録する。
