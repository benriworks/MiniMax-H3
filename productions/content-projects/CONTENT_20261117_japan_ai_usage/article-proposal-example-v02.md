# 仕事でどこから始める？　自社テンプレートから顧客別提案書へ

提案書は、書式を整える前に、お客様の課題、自社が提供できる内容、試す範囲をそろえる必要があります。Claude Codeのエージェントに自社のテンプレート、お客様との商談メモ、自社の提案条件を渡し、顧客別の提案書の初稿を作ってみました。

架空のお客様は青葉製作所。3拠点の工場でExcelの日報様式が異なり、本社の集計に週6時間かかる設定です。エージェントは3つの資料を読み、テンプレートの「お客様の課題」「提案内容」「導入計画」「見積・納期」の順に初稿を保存しました。

| 初稿の項目 | 青葉製作所向けの内容 |
| --- | --- |
| お客様の課題 | 拠点ごとに日報の様式が異なり、集計に週6時間かかる |
| 提案内容 | Excelの日報の記入項目をそろえ、共通様式から集計できるようにする |
| 導入計画 | まず1拠点で試し、集計時間と入力漏れの変化を確認する |
| 見積・納期 | どちらも「要確認」。全拠点への展開は試行結果を見て判断する |

提出前に人が元の資料を開き、見積の根拠、約束した納期、対象とする拠点を照らし合わせます。例えば、初稿には「担当者ごとに集計基準が揺れる」という説明が入りましたが、今回の商談メモにあったのは「同じ基準で集計できるようにしたい」という要望です。顧客に確認して表現を直し、見積と日程が決まってから提案書を仕上げます。
