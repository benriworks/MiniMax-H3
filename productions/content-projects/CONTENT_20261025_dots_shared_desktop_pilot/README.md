# dotsクラウドデスクトップの短編試作

2026-10-25開始。動画の冒頭1〜2秒に完成物を置き、1本1用途で20〜35秒を試す企画。中心メッセージは「クラウドが、dotsとあなたの共有デスクトップになります」。ここでの共有は、同じクラウドPCを見て操作を交代できるという説明上の表現であり、同時に二人がマウスを操作したり、手元PCが同期されたりする意味にはしない。

- [3本の構成案](PROPOSAL_V01_JA.md)：各回の完成物、操作、結果、注意点、見出し、予定尺。
- [記事草稿](article-draft-v01.md)：投稿先は既定のbenriworks/blog。noteにも派生可能。未公開。
- [出典](SOURCES_JA.md)：公式本文を実際に確認した内容と確認日。
- [撮影とレビューの記録](CAPTURE_AND_REVIEW_JA.md)：撮影可否、原本、未取得素材、文章点検。

推奨は3本（30秒、25秒、30秒）。同じ長い動画を分割するのでなく、操作交代、数値の可視化、ブラウザー調査という用途を分ける。既公開の「PCを閉じても進む」補足を繰り返すだけにしない。短尺化と完成物の先出しは検証仮説で、再生数や視聴継続の改善を保証しない。

現時点は企画案。構成の採用、実演用の新規依頼、完成物の取得、本番音声・人物動画生成、レンダー、Drive納品は未実施。実機ではクラウドPCを開き、ライブ映像と操作引き継ぎボタンの表示・保存を確認した。既存作業が映っているため原本は非公開に分離し、公開用の架空実演が完成したとは扱わない。

人物は既存dots編の男女を引き継ぐ方針。新キャラを作らない。参照は `productions/characters/programmer-duo/` と `productions/characters/motion-registry-20261022.json`。既存生成物の `user_approved:false` は維持し、顔・衣装の継続と完成クリップの採用を混同しない。人物は完成物を見た気づき・次の行動に短く使い、冒頭の成果物表示を人物の挨拶で遅らせない。Aoedeを継続し、制作都合の注釈を入れない。

案件出力は `outputs/content-projects/CONTENT_20261025_dots_shared_desktop_pilot/`。撮影原本、公開候補、記事受け渡し、CLI入力・結果を版付きで保存する。文書は個人fork、動画・音声・ZIP・非公開原本はローカルと必要な共有先に置く。
