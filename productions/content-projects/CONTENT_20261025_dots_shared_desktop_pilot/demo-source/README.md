# 撮影用デモのソース保管

2026-10-25にdotsクラウドPC内で実際に作成・使用したコードを、資産化のためコピーしたもの。実行原本と完成物は案件出力の `cloud/v01/dots-desktop-pilot-20261025/` にあり、59ファイルの照合記録で追跡する。

- `invitation/`：架空メモ、初回と修正後のテキスト、GUIで編集・localStorage保存する画面。
- `case-demo/`：実.xlsxを読む専用ビューア、架空案件の入力・確認・デモ登録・再表示、入力検証。サーバーは127.0.0.1限定。実サービス連携はない。
- `blender/`：初回モデルの生成参照、別名コピーからの厚み修正・レンダー、ファイル数値検証。

動画・音声・.blend・.xlsx・画像・ZIPはこのGit保管フォルダーへコピーしていない。再現する際は、ローカルの完成物を別の作業フォルダーへコピーし、必要な原素材を揃える。

`build-workbook.mjs` はクラウド環境で使用した出力先とArtifact Tool依存をそのまま保持している。ローカルで実行する前に出力先を新しい作業フォルダーへ変更し、利用する実行環境を確認する。生成済み.xlsxの閲覧にはこの生成ライブラリーは不要。

Blenderの生成コードは新しいバックグラウンドプロセスで使う。開いている作業中シーンへそのまま実行しない。初回シーンの生成コードにはシーン初期化があり、修正版の生成コードも生成先ファイルを保存する。撮影原本を上書きせず、新しい版へコピーしてから再現する。

受領した疑似システムの7テストはローカルでも成功した。これは入力検証と.xlsxの読み取りの検査であり、ローカルで再度GUI登録をした証拠ではない。クラウドでのGUI実演記録と分ける。
