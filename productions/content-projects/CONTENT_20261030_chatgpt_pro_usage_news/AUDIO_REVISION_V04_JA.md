# BGM音量の改訂v04

2026-10-31。[ユーザー原文と反映方針](bgm-feedback-20261031.json)を共通台帳revision 28へ保存した。v03の人物・映像への肯定的評価を引き継ぎ、音楽だけを改訂する。v04の最終試聴・採用・公開は未確認。

## 音量の設計

| 項目 | 設定 |
| --- | --- |
| 同じ明るいBGMの通常部 | 従来の基準ゲイン1.3に対して+4dB |
| 冒頭1.4秒・終わり2.2秒 | 通常部に最大+3dBを滑らかに加算 |
| 音楽フェード | 立上がり0.7秒→0.08秒、終端3秒→0.25秒 |
| 発話中 | BGMを0.2倍。開始前0.12秒・終了後0.25秒で滑らかに減音・復帰 |
| ナレーション | 同じAoede原本6件、同じ時刻・ピーク基準0.82。追加生成0 |
| 映像 | v03のH.264をstream copy。再描画・人物再生成0 |

頭と尾の長いフェードを短くしたため、BGMステムの実測RMS差は冒頭0〜1.4秒が+13.16dB、通常2〜45秒が+4.05dB、終わり45.8〜48秒が+16.86dB。設定の+3dBは区間補正であり、旧版との総差ではない。これらは音楽ステムの比較で、声や全体ミックスを一律にその差だけ上げたという意味ではない。

## 実行と検査

`verify_bgm_v04.py` で旧ミックスの再構築、声のPCM一致、BGM差、最終AAC音量と出力hashを再検査できる。

`remix_bgm_v04.py` が検証済み音声原本を読み、共通 `tools/studio/music_mix.py` で音量カーブを作る。共通 `music_bright()` はフェード時間を任意指定できるようにし、既定値の音源は従来どおりに維持した。音源の位相・曲調・112 BPM・Cメジャーを変更していない。
