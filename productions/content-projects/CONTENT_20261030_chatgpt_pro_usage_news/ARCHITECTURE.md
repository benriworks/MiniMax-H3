# Pro利用枠ニュースの制作構成

2026-10-31。Studioアプリ本体とは独立した案件専用ドライバー。旧版の企画・撮影原本・レビューPDFは保持する。

`approval-20261031.json` の原文と反映方針を共通ContentWorkspaceへ保存し、`accept-20261031.json` で約48秒の提案v01を採用する。`sync_workspace.py` は共通サービス経由で参照静止画、架空成人の役割、今回の採用範囲、再利用するMiniMax動画を登録する。動画の最終採用や公開へは昇格しない。

`produce.py voice` は既存Geminiアダプターを使い、Aoedeで6場面を逐次生成する。22秒以上の送信間隔を設け、保存済みの原稿・WAV・hashを照合し、結果不明や拒否を自動再送しない。APIキーは環境変数のみ。モデル可用性は事前の読取確認と本番要求の結果で判断する。

`preview` と `render` はPillowで人物動画、相対グラフ、字幕、短い公式引用、確認先の実画面を合成する。人物動画は元制作フォルダーのMiniMax出力とSHA-256照合済みコピーを使い、元音は使用しない。既存人物の自然な動きであり、音声に一致する新規リップシンクを生成したものではない。共通の明るいBGM生成器を再利用し、発話中は減音する。実PCM尺を保ち48秒へ読取り余白を配分する。収まらない場合は発話を切らず延長する。

グラフの基準は各対象プランの従来枠を1とする相対値。利用実績、回数・時間の絶対量、異なるプラン間の量比較、タスク完了数を示さない。Pro200の高い枠には倍増アニメーションを適用しない。

素材、WAV、動画、QC、Drive受領記録は `outputs/content-projects/CONTENT_20261030_chatgpt_pro_usage_news/` に置く。Gitにはコード・採用原文・出典・工程・記事草稿だけを保存する。Driveは接続ツールで個別送信し、Studio内の自動送信や自動公開は追加しない。全編decode等の技術検査と、AI補助確認、人の試聴、スマホ再生、採用、公開を分離する。
