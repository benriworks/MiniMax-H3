# Claude Code、何がすごい？ 30秒ショート

2026-09-26の依頼「ClaudeCodeのすごさ！みたいな30秒ショート動画」に対応する縦型紹介動画。冒頭に男性プログラマー、結末に明るい服装の女性プログラマーの既存MiniMax H3素材を使用する。中盤は独自の図解アニメーションで、開発の流れを説明する。

## 制作と出典

- 仕様：1080×1920、24fps、30秒、720frames。文字は最低54px（360px表示で18px）。
- 声：Microsoft Sayaka、速度1。「Claude Code」は「クロードコード」と読む。
- 音楽：今回用に数式で合成した112 BPMのBGMと切り替え音。声の区間は音楽を下げる。
- [台本](story.json)／[公式出典と表現範囲](SOURCES_JA.md)
- 以前のMiniMax H3素材を媒体hashと生成記録で照合して再利用する。新たな生成API呼び出しはない。
- 中盤は実操作の録画ではなく、説明用のアニメーション。画面に「図解イメージ」を表示する。
- 2026-09-29の利用者指定：動画とカバーに「MiniMaxで作成」などの生成ツール名のテロップを入れない。素材の生成元は制作記録に残す。

## 再現

```powershell
.\.venv\Scripts\python.exe productions/SHORT_20260926_claude_code_wow_30s/produce.py prepare
node productions/SHORT_20260926_claude_code_wow_30s/render.mjs <prepareの出力先>
.\.venv\Scripts\python.exe productions/SHORT_20260926_claude_code_wow_30s/produce.py finish <同じ出力先>
```

台本の各音声が5秒枠へ収まることを実測し、制作ソースと入力映像をhashで固定する。完成映像を再圧縮せずに音声を合成し、全decode、30秒・720frames、AAC 48kHz、音声peak、スマートフォン幅の文字を検証する。技術・目視確認と利用者による採否は別に記録し、YouTubeへの公開は行わない。

映像だけの改訂は`produce.py prepare --reuse-audio <検証済み前版の出力先>`を使用する。台本・音声設定・音楽設定と既存成果物のhashを照合し、前版のAACをそのままコピーする。完成後に音声packetのhash一致を検証する。
