## 生成画像

- モード: `imagegen` スキルに従った内蔵画像生成ツール。CLI / OpenAI Image API用のAPIキーは使用しない。
- 実行: 新規生成1回。参照写真や第三者の人物画像は送信していない。
- 保存先: `outputs/productions/SHORT_20260905_claude_desktop_15s/assets/desktop-hero.png`
- PNG: 941×1672、1,456,308 bytes。
- SHA-256: `1BAC7370D602485B50F5867AEE68445D97A2570104D41D6280ABE2ADDB512302`
- 正確な送信プロンプト: [prompts/DESKTOP_HERO_IMAGEGEN.md](prompts/DESKTOP_HERO_IMAGEGEN.md)
- ラップトップの画面は生成時に無地にし、架空の製品画面や読めない生成文字が実UIと誤認されないようにした。操作カードは写真と独立した図解として後段で合成する。
- ツールが保存した原本は `.codex/generated_images` 内に保持し、上記workspace内のコピーをレンダラーの入力とする。欠落時は別画像へ黙って置換しない。

画像生成はリモートの内蔵サービスを使用している。後段のローカル合成manifestの `network_used:false` は合成工程だけの説明であり、制作全体が完全オフラインだったことを意味しない。内蔵画像生成の消費量・費用はこのリポジトリでは測定していないため、制作全体を「無料」と断定しない。

## 公式情報と表現

[Claude Code公式デスクトップ入門](https://code.claude.com/docs/en/desktop-quickstart)を本文まで確認した。

- `Code` タブでLocalプロジェクトのフォルダを選び、依頼を入力し、変更をレビューできる。
- デスクトップアプリにはClaude Codeが含まれ、CLIの別途導入は不要とされる。ただしWindowsのLocalセッションにはGitが必要で、無条件の「セットアップ不要」とは表現しない。
- 対象の有料プランが必要。映像に条件を明示し、投稿説明にPro / Max / Team / Enterpriseを記載する。
- 適用前の承認・自動適用後のレビューは権限モードで異なる。「必ず事前承認される」「確認不要」「修正が必ず成功する」とは説明しない。
- 画面の構成、コード差分、ボタンの色変更は説明用であり、実画面収録や実行ログではない。全カットに操作イメージの表示を入れ、写真カットにはAI生成表示も入れる。
- ロゴマークは使用しない。Claude / Claude Codeは紹介対象の名称として表示する。個人制作の非公式解説でありAnthropicの承認を示さない。

## その他の素材と確認境界

- 音声: ローカルWindows SAPIのMicrosoft Haruka Desktop。実在人物の声のクローンではない。
- SAPIの句末に含まれる長い静音だけを制作専用処理で調整し、raw / trimmed WAV、判定条件とhashを残す。発話速度は実測結果に基づいて選ぶ。
- フォント: WindowsローカルのYu Gothic UI / Yu Gothic系。フォントのダウンロードやファイル配布はしない。
- BGM、効果音、外部TTS API、MiniMax API、YouTube投稿は使用しない。
- 再生成ソース・台本・出典・監査用hashはGit追跡対象。PNG / MP4 / WAV / レンダーキャッシュはignoredの`outputs/`に保持する。
- 機械的QCは自然な発音・人による最終試聴・公開判断を代替しない。
