# Claude Code デスクトップ版: 15秒ショート計画

制作ID: `SHORT_20260905_claude_desktop_15s`

今回は「アプリで使える」「フォルダを選ぶ」「変更を確認する」の具体的な手順を、3カットで紹介します。クリーム・チャコール・テラコッタの落ち着いた配色と大きな文字を使い、カット2には画像生成スキルで作成した実写調のデスク写真を大きく入れます。全カットで操作説明用の図であることを明記します。

| カット | 素材尺 | 画面と動き | 読み上げ |
| --- | --- | --- | --- |
| 1 | 126frame / 5.25秒 | 「Claude Code、アプリで使える。」。Chat / Cowork / Codeの簡略タブを表示し、カーソルがCodeを選択。Localとフォルダ選択へ進む | Claude Codeは、 / アプリでも使える。 |
| 2 | 126frame / 5.25秒 | 「フォルダを選んで、やりたいことを入力。」。デスク写真をゆっくり寄せ、my-project選択と「ボタンの色を変えて」の入力カードを重ねる | フォルダを選んで、 / やりたいことを入力。 |
| 3 | 120frame / 5.00秒 | 「変更を見て、自分で確認。」。ボタン色の変更前後と小さな差分を示し、「まずは、小さな修正から。」で結ぶ。「対象の有料プランが必要」を表示 | 変更を見て、確認。 / まずは小さな修正から。 |

素材の合計15.5秒から、2箇所の250msフェードを引いて完成15秒にします。すべて1080×1920・24fps・無音H.264 MP4です。大見出しを素材側へ描画するため、後工程は `overlay: null` とします。ナレーションと下部字幕は制作専用の実行スクリプトで既存のSAPI・Remotion・assembly・QC処理を使って追加します。通常のQuickCreate画面から生成した動画ではありません。

## 表現と根拠

- 操作図は簡略化した説明用で、実アプリの画面キャプチャではありません。「操作イメージ（実画面ではありません）」を全カットに表示します。
- 写真は画像生成スキルで作成し、カット2に「AI生成ビジュアル・画面は説明用」と明記します。
- Codeタブ、Localでのフォルダ選択、自然言語による作業依頼、差分の確認は[公式デスクトップ版クイックスタート](https://code.claude.com/docs/en/desktop-quickstart)に基づきます。
- カット3は変更例を説明するもので、毎回特定の承認ボタンが必須であるという描写や、実際に完了したテストの表示ではありません。
- 対象の有料プランが必要である点を画面へ記載します。プランやWindowsでのLocal利用条件などの詳しい説明は投稿情報へ記載します。

重要文字はx=96〜896、y=292〜1450付近に収め、下部y=1520〜1660は後工程の字幕用に空けます。フォントはWindowsのYu Gothic系とConsolasで、外部フォントは使用しません。

## 必須の生成画像

画像ファイル: `outputs/productions/SHORT_20260905_claude_desktop_15s/assets/desktop-hero.png`

写真はライトウッドの机とノートPCを中心にした実写調ビジュアルです。実アプリのロゴや本物の画面を装う表示は使いません。生成画像が存在しない場合、静止画・動画のどちらのレンダーも停止します。仮の画像で完成扱いにはしません。

## 再現コマンド

リポジトリルートで代表静止画を生成し、目視確認後に動画をレンダーします。

```powershell
node productions/SHORT_20260905_claude_desktop_15s/render.mjs --stills
node productions/SHORT_20260905_claude_desktop_15s/render.mjs --videos
```

出力先: `outputs/productions/SHORT_20260905_claude_desktop_15s/sources/`

- `cut_01_desktop.mp4`
- `cut_02_folder.mp4`
- `cut_03_review.mp4`
- 代表PNG、`stills-report.json`、`sources-report.json`

レポートへ生成画像のSHA-256とサイズ、compositionのSHA-256、各動画の時間・サイズ・SHA-256を保存します。依存ライブラリは既存の `studio/node_modules`、ブラウザーは同じPlaywrightが指すインストール済みChromiumです。
