## 改訂の内容

- 01：Claude Docs。資料を参照し、人が直接編集し、Claudeへコメントで相談して同じ文書を仕上げる45秒。旧タイトル「メモからDocsへ！下書きと修正、数字まで確認」から主題を変更。
- 08：dotsの先回り提案。許可されたメールや予定から変化に気づき、次の行動を提案。会議の前倒しと資料準備は架空の例。
- 09：承認が必要な操作の前に確認が来たら、ユーザーが実行、修正、中止を判断。許可や設定によって毎回確認されるとは限らないことも説明。
- 07：第8回への予告だけを「先回り提案」に変更。他の検証済み音声を再利用。

## 制作と証拠

`produce.py build`で全場面の文字量と字幕を検査。`generate`は既存のGemini Aoede生成処理を使い、完全一致する発話だけ再利用する。共有ロックと送信間隔を維持し、不明な送信結果を自動で再試行しない。`render --episode N`で既存のStudio共通処理へ渡す。

01の`creator-story.json`は音声計画の原本。`visual-v03/creator-story.json`は「見出しと表」の場面へ日程表が見える保存済み実画面を指定した表示改訂。音声は変更していない。旧映像候補は削除しない。

Docsの実画面は2026-10-22の架空店舗「灯台珈琲」の記録。複数資料の利用、直接編集、複数人同時編集は公式説明であり、今回新しく操作して撮影したという主張をしない。人物は既存の栞とdotsの2人を継続し、MiniMaxで生成済みの人物動画を全面使用する。

## 保管とレビュー

動画、音声、画像原本、非公開共有先は`outputs/`へ保存する。レビューは版付きのGoogle Driveフォルダーを使用し、ファイル名、容量、親フォルダー、アクセス状態を再取得する。モバイル実再生、最終試聴、採用、公開は別の確認項目とする。

GitHubにはこの説明、構成、ドライバー、公開可能な検査要約を残す。動画本体、音声、非公開原撮影、Drive URLは保存不要。記事はbenriworks/blogのPR #85でdraftを維持する。Studioの共通機能に変更はなく、今回の編集は案件固有の改訂である。
