# レビュー依頼・回答記録のひな形

山括弧内を実際の値へ置き換えて依頼文を作る。対象ファイルを確認してからリンクを渡す。署名付きURLを記入した完成メッセージは、GitHub・台帳・このひな形へ保存しない。

## 1. はじめの人物確認

```text
＜シリーズ＞の案内役候補を作りました。
対象：＜キャラID・画像版＞
人物設定：＜架空の成人、仕事、性格、相方との役割＞
確認用：＜顔・全身・動画の構図の画像／比較ページ＞
確認してほしい点は、①顔と雰囲気、②衣装、③役割です。
採用する候補か、変更したい点を教えてください。
確認後、この人物をMiniMaxで動かす短い動画を作ります。
```

## 2. 初稿・修正版・最終版

```text
＜案件ID／回／版＞の＜初稿・修正版・最終確認版＞です。
YouTube見出し：＜見出し＞
今回の変更：＜具体的な変更と対象時刻＞
再生：＜リンク＞　MP4保存：＜リンク＞
リンク期限：＜年月日・時刻・日本時間＞
確認してほしい点：
1. ＜例：00:00〜00:05の人物の大きさ・表情＞
2. ＜例：字幕の読みやすさ＞
3. ＜例：Aoedeの速さとBGM込みの聞き取り＞
こちらで確認済み：＜媒体・画面等、実際に確認した範囲＞
未確認：＜最終試聴等、残っているもの＞
修正は「00:08、文字を大きく」のように時刻付きでお願いします。
```

| --- | --- | --- | --- | --- |
| 未記入 | | | | |

「声がよい」はその声の採用、「この顔がよい」はその画像・人物の採用として記録する。別の動画全体、全話、公開までの承認には広げない。返答なしは承認ではない。既に確認された同一範囲は再質問せず引き継ぐ。
