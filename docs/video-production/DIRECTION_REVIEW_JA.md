# 文書整理後の方向性検討シート

作成日：2026-10-23。これは次の話し合いのための資料であり、下記の候補を採用・実装・量産する指示ではない。

## 現在の到達点

- 人物動画、公式引用、実演、図解、Aoedeナレーション、字幕、投稿見出しを組み合わせる制作経路がある。
- 直近の確認対象は比較75秒1本、Claude30秒5本、dots30秒5本。媒体と画面、S3からの取得を確認済み。最終試聴・採用・公開は個別の記録を確認する。
- 人物を全面に使う演出へ変更した。今後は同一人物でも動作・構図・物語を変え、単調さを抑える余地がある。
- 文書を整備したことと、ユーザーが次の方向性を決めたことは別である。

## 検討する軸

| 軸 | 候補 | 決める基準 |
| --- | --- | --- |
| 視聴者 | 初心者／仕事で試したい人／開発者 | 誰のどの困りごとを解決するか |
| 内容 | 新機能の速報／架空業務の実演／製品比較／使い方の連載 | 見たあと試せること、公式根拠、継続して作れること |
| 人物 | 元の男女／控えめなビジネス人物／シリーズごとの固定案内役 | 親しみやすさ、視聴者との関係、承認済みの範囲 |
| 物語 | 1本完結／同じ仕事を複数話で進める | 単独視聴と連続視聴の両立 |
| 尺 | 30秒／45〜60秒／比較・実演は長め | 説明の正確さ、テンポ、見る負担 |
| 素材の比率 | 人物中心／実画面中心／場面ごとの使い分け | 顔の動きで伝えることと、画面で証明すること |
| 音声 | Aoedeを統一／一部Koreを比較 | 聞き取り、シリーズの一貫性、試聴結果 |
| 制作量 | まず1本／少数のシリーズ／定期制作 | レビュー負担、生成費用、修正時間 |
| 振り返り | 視聴者の反応、完視聴、疑問点、制作時間 | 実データを確認し、取得していない数値を推測しない |

## 次回決めること

1. 誰向けに、どのテーマを1本作るか。
2. 継続する人物と、その人物が取り組む仕事・課題。
3. 最初の1本の尺、実演内容、声、見出し。
4. 見てもらうタイミングと、良かったかを判断する基準。
5. 量産する前に確認することと、制作回数・時間の目安。
