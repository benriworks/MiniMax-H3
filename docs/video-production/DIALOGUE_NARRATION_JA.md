# 会話で進める実演とBGMの改訂


> 2026-10-30：制作の入口は [索引](README.md) → [総覧](PRODUCTION_KNOWHOW_JA.md) → 対象案件の `RESUME_AND_KNOWHOW_JA.md`。本書は工程別の詳細資料として併用し、案件の現在地・次の作業・新しい学びは再開記録へ反映する。

2026-10-26、dotsの転記詳細動画で採用された制作方向。人物の役割は案件ごとに決める。この案件では男性が視聴者の疑問を代弁し、女性が目的を答え、実演を案内する。別シリーズへ男女の役割を自動適用しない。

2026-10-28整理：題名・完成像の先出し・フル動画全体の型と採用履歴は [編集基準](EDITORIAL_PATTERNS_JA.md) を正本とする。この別冊は会話原稿・音声の生成と配置を扱う。

## 会話の構成

冒頭は「今日は、どんな作業をやりたいの？」→「Excelの三件を、案件管理の画面へ移したいの」のように目的を具体化する。進行役がすべてを解説する形に戻さず、実務を担当する人物が「まずここを確認するね」「次は入力してもらうよ」と進める。

質問は視聴者の判断に役立つものにする。「どの情報を移す？」「確認ボタンで保存は終わり？」「合計が合えば完成？」など、操作の前提や誤解しやすい点を引き出す。説明文を二人で交互に読むだけにしない。質問の直後は短く返答をつなぎ、画面を読む間は返答や作業説明の後へ置く。操作映像の速度を音声に合わせて変えず、必要な時間は明示した静止説明・図・要点画面へ配分する。

人物の会話は実演の案内であり、本人の承認や実操作担当者の発言を捏造しない。実際の承認の取得経路・保存先・確認範囲を別の記録で残す。

会話から未知の製品・作業場所の実画面へ突然切り替えない。必要なら起動画面と短い説明で「何か／どこで／何を頼めるか」をそろえる。dotsの起動画面による導入説明は追加依頼として残っており、まだ音声化・映像挿入・後続時刻更新を完了したものではない。追加台詞の原稿・生成記録と既存台詞の再利用範囲を分けて扱う。

## 生成と配置

共通 `dialogue_narration.payload(..., profile='conversational_v3')` は正確な引用台詞を、少し速めの自然な成人同僚の会話として音声化する。質問を回答として解釈しない、話者名や余分な言葉・BGMを加えないと指定する。声は案件で採用されたAoede／Charonを維持する。

表示原稿と読み原稿を分け、dots＝ドッツ、Excel＝エクセル、表＝ひょうなどを対象語句単位で指定する。「表」を一括置換して「表示」を壊さない。既存の排他・送信間隔・要求保存・成功hash検査・拒否と結果不明の自動再送禁止を継続する。

`longform_audio.plan_dialogue` の任意指定 `pause_mode='after_answer'` は男性の質問と女性の返答の間を0.35秒に保ち、余分な画面読取時間を女性の返答後へ配る。この配分は今回の役割分担向け。既存の既定配分は変えない。PCMの全サンプルを残し、章が短ければ必要尺へ延ばす。字幕は音声実尺から配置するが、語単位の強制アライメントではない。

## 明るい伴奏

`longform_audio.assemble_audio(..., music_style='bright')` は112 BPM・Cメジャーの短い撥弦和音、マリンバ風の音、軽いシェーカーを生成する。長く伸びる低いパッドは使わない。2026-10-31以降は[BGM既定設定](BGM_DEFAULTS_JA.md)の通常ゲイン約2.06036、頭尾最大+3dB、発話中0.2倍、短いフェードを既定で使う。従来の0.32倍はlegacy再現時の値。既定の `calm` は従来の88 BPMを保持する。

声・伴奏・仮ミックス・最終音量測定を別保存し、最終MP4で音切れ・聞き取り・BGMの主張・左右バランスを確認する。明るい曲調と音量の大きさを混同しない。最終試聴や曲調の好みは人の判断として記録する。

## レビューと保存

旧版を保持して別バージョンへ書き出す。確認用抜粋は質問と返答を途中で切らず、冒頭・要点・締めを含める。Driveに全編と抜粋を置き、対象版、変えた点、確認してほしい会話とBGMを案内する。AIによる全文音声点検、媒体検査、人の最終試聴、ユーザー採用は分ける。人物PIPの口はPCM強度に反応する簡易方式で、音素に厳密同期した生成動画とは記載しない。

動画と並行して記事草稿・出典・画像台帳を版に追従させる。音声と演出だけの改訂を新しい実画面の撮影・製品の再実証としない。コード、台本、改善理由、検証要約をGitHubへ残し、動画・音声・ZIP・共有URLはローカルと共有ストレージへ保存する。
