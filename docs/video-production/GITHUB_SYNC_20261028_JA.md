## 検証とテストの再利用性

- Studioの235テストと比較演出の7テスト、TypeScript/Vite production buildを確認した。buildには既存の500 kB超チャンクの注意表示がある。
- 全体回帰の初回は947件を実行し、2件のエラーと1件のskipが出た。HTTP接続がWindowsにより中断されたケースと、ファイル更新時刻を利用するケースで、両方とも単独再実行では通過した。初回を全件成功と扱わない。
- 後者は同じ時刻が残り得る `touch` の代わりに、テスト内で異なる更新時刻を明示し、同一サイズ変更の検出という検証内容を保った。
- 撮影画像に依存する保護テストは、一時フォルダーに作る架空PNGと証明レコードへ変更した。実撮影・製品実証とは別の単体テスト素材で、音声生成前に未検証画像と範囲外切り出しを拒否する点を確認する。
- 会話音声の安全性テストは、初回cloneに `outputs` がない場合も動く独立した一時フォルダーを使う。拒否・結果不明の自動再送を防ぐ検証を維持し、プロバイダーはモックする。
- 上記修正後の関連Pythonテスト152件が、統合worktreeで通過した。全体947件を修正後に再実行したという意味ではない。テストログ、対象一覧とローカルの差分監査記録は元制作フォルダーの `outputs/docs/video-production-20261028/` に保持する。

追加ファイルとmainとの差分は、秘密情報・有効な署名パラメーター・競合マーカー・JSON構文・サイズ・メディア拡張子を点検する。GitHubのCI状態が未設定であることと、ローカル検証の成功を区別する。
