# 解説動画の演出・編集プレイブック

更新日：2026-11-03。登録者10万人以上の20チャンネル、各1本の比較調査から整理した制作上の選択肢。[比較対象・動画リンク・時刻・確認方法](research/YOUTUBE_EXPLAINERS_20_20261103_JA.md)と併用する。以下の番号は比較表のチャンネル番号。

これは私たちの制作へ適用する判断であり、各チャンネルの制作規約や成功要因の証明ではない。60項目には、今回の観察と結び直した既存規約の継続も含む。観察はAIによる映像・音声分析を含む。登録者数・再生数から特定演出の効果を断定しない。全部の技法を毎回詰め込まず、その回の理解に役立つものを選ぶ。

## まず次の1本で変えること

1. 完成品を全面で先に見せ、視聴者の疑問を一つ置く。
2. 静止スライドを連打する代わりに、同じ図へ説明の順に要素を足す。
3. 聞き役の疑問→画面の証拠→短い納得、を一組にする。
4. 字幕・図中ラベル・章見出しの役割を分け、同じ長文を重ねない。
5. 操作や数字を読む場面では人物を退避し、見る時間を残す。
6. 締めは冒頭の疑問へ答え、次に見る動画・詳細記事へ具体的に接続する。

既存の男女・声・やわらかい会話、3D／簡略モデル表記、`explanation_v1`のBGMは継続。過去動画を一括で再制作しない。登録者増・視聴維持の効果は、公開後に検証する。

### 尺を決める際の出発点（私たちの検証案）

以下は調査動画の平均値ではない。まず試す編集案で、実音声・可読性・操作時間へ合わせて変える。

| 場面 | 試す長さ・判断 | 切り替える条件 |
| --- | --- | --- |
| ショート冒頭の結果 | 最初の1〜2秒から結果が分かる画を置く | 複雑な図を2秒で読ませるという意味ではない |
| 身近な例・短い反応 | 約2〜4秒を検討 | 新しい意味がない相づちは省く |
| 一つの図解ステップ | 約3〜6秒を検討 | 一文と一変化が対応し、読めるまで保持する |
| 画面操作・数字の照合 | 必要なら6〜15秒以上 | 保存・値・状態が見えるまで。一定秒数で強制カットしない |
| 連続する動作・模型の確認 | 動きの因果が分かるまとまり | 部分を切り出して意味を変えない |
| フルの終了画面 | 案件別に約10秒を検討 | 既存指定を尊重し、全動画へ一律適用しない |

## 制作へ落とす短い例

題材：dotsにBlenderを動かしてワインCGを直してもらう。これは構成の例であり、新しい実演・制作済み動画ではない。

| 段階 | 画面 | 台詞の意図 | 人物 |
| --- | --- | --- | --- |
| 結果 | 完成CGを全面で見せる | 『この動き、修正まで頼めるの？』 | まず成果物を優先 |
| 疑問 | 同位置の修正前後を切り替える | 『瓶、小さくない？』→『比率を見て直してもらったよ』 | 質問で短く登場、比較では退避 |
| 仕組み | 自分の端末→クラウドPC→Blenderを順に点灯 | 『クラウドPCのBlenderで作業するんだ』 | 図の説明を隠さない |
| 実演・確認 | 取得済み実画面、修正依頼、保存物 | 『どこを変えたいか伝えて、ここで確認するね』 | 値・操作・細部では退避 |
| 締め | 完成CG→要点→関連動画・記事の余白 | 『頼んで、見て、直す。詳しい手順は記事で』 | 納得・安心の表情で短く戻る |

本書の追加だけでStudioへ自動カット判定・視線制御・Analytics連携が実装されたわけではない。助手が絵コンテとレビューで適用する文書上の運用として扱う。
