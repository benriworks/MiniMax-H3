# BGMの既定設定

更新：2026-10-31。ユーザーの「今調整したBGMの音量などを既定にして下さい」により、[Proニュースv04](../../productions/content-projects/CONTENT_20261030_chatgpt_pro_usage_news/AUDIO_REVISION_V04_JA.md)の音量設計を今後の制作の出発点として採用した。曲・声の選択とは別のミックス設定である。

| 項目 | 既定値 |
| --- | --- |
| プロファイルID | `explanation_v1` |
| 通常のBGMゲイン | `1.3 × 10^(4/20)`（約2.06036）。Pro旧基準1.3から+4dB |
| 冒頭 | 1.4秒間、最大+3dBから通常へ戻す |
| 終わり | 最後2.2秒で強調を開始し、終端手前では最大+3dB |
| 発話中 | BGMを0.2倍へ減音（約-14dB）、開始前0.12秒・終了後0.25秒で滑らかに移行 |
| フェード | 冒頭0.08秒、終端0.25秒 |
| 最終音量の検査範囲 | -18〜-14 LUFS、true peak -1dBTP以下。最終AACで確認 |

正本は `tools/studio/music_mix.py` の `DEFAULT_BGM_PROFILE`。`default_bgm_bed()` にフェード前のステレオ音楽と実音声の区間を渡す。`longform_audio.assemble_audio()` と `shorts_creator.sound_design()` はこの設定を既定で使用し、台帳へ設定を保存する。音声・効果音・曲の選択は変更しない。別の音源は収録レベルが異なるので、このゲインが必ず同じ聴感になるとは扱わず、声の聞き取りと最終peakを確認して案件ごとに調整できる。

既存の完成MP4、原本、過去の検査値は更新しない。旧版の再現時だけ `bgm_mix_profile='legacy'` を明示する。Shortsのstory JSONでも同じキーを使う。旧preparationに設定がなければlegacyと判断し、新既定の制作へ古い音声ミックスを誤って流用しない。ナレーション原本の再利用とは分ける。

歴史的な案件専用スクリプトの固定値は再現用に保持する。新規案件の専用処理はこの共通設定を使い、旧スクリプトをそのまま複製しない。既定変更だけのために新しいTTS・人物生成・動画書出し・再共有はしない。BGM既定の採用は動画全体や公開の採用と分ける。

検査：音楽関連12テストと長尺・Shorts関連12テストを実行。新共通BGMがv04の明示設定とサンプル一致、声・効果音の保持、legacyの従来PCM一致、旧ミックスの誤再利用拒否を確認した。新しい完成動画やスマホ試聴の検査ではない。
